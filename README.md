# Purrkour 🐈

Jeu de parkour félin mobile-first, développé avec React, TypeScript et Three.js.

## Développement local

```bash
pnpm install
pnpm dev
```

## GitHub Pages

La publication est automatisée via `.github/workflows/deploy-pages.yml` dès que le code de l’application est présent sur `main`.

Site attendu : https://salfab.github.io/Purrkour/
